# 案件由来AIノートを一律転送不可にしていた

- Date: 2026-08-31
- Status: fixed in working tree
- Area: AI Hub / Notion transfer safety
- Severity: content publishing blocker

## Summary

Notion転送前チェッカーは案件由来の記事を一律に転送不可としていたため、固有名詞と個人環境情報を
除去すれば再利用できる技術記事まで公開候補から落としていた。安全性を保ちながら汎用化レビューへ
回す区分が欠けていた回帰である。

## Evidence

- 2026-08-31、複数の案件由来記事について、案件固有名を除けば汎用技術として
  書き直せるとユーザーから報告された。
- `checkNotionTransfer` はすべての finding を同じ転送不可条件として扱い、書き直し可能性を
  表現していなかった。

## Regression Context

案件機密の見逃し修正で fail-closed を優先した結果、検知と最終公開可否を同一視して過剰遮断した。

## Cause

秘密値・R18のように汎用化しても原文を扱うべきでない所見と、案件名・ローカル構成のように
除去後の再検査で救済できる所見を分類していなかった。

## Fix Requirements

- 判定をそのまま転送可・汎用化候補・転送不可の3区分にする。
- 案件名、案件 provenance、環境変数、ローカルパス、loopback、個人環境文脈を汎用化候補にする。
- 禁止語、秘密鍵、token、メールアドレス、R18、不正 provenance は転送不可を維持する。
- 汎用化候補の原文は転送せず、書き直した title/body の再検査通過を必須にする。

## Verification

- ユーザー指示によりテストは実行しない。
- 実データへの読み取り専用実行で、対象記事が汎用化候補になることを確認した。
- 全記事が、そのまま転送可・汎用化候補・転送不可のいずれかに分類されることを確認した。
- 回帰テストは3区分と、汎用化可能・不可能な所見の境界を固定する。

## Follow-up

汎用化候補の実際の書き直しとNotion転送は、人間の編集確認を経て別工程で行う。
