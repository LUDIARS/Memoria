# SPEC-MM-ERROR-LOG

「ログ」の左端と初期表示を「エラー」にする。既存の日付別ログはその右に残す。
HTTP 400以上の失敗をSQLiteに最大500件保存し、最新200件を時刻順で表示する。
記録項目は時刻、HTTPメソッド、クエリを除いたパス、ステータスのみ。
本文、Cookie、認証ヘッダー、スタック、クエリ文字列は記録しない。
履歴APIはMemoriaの既存Access保護済みブラウザ境界を使い、キャッシュしない。

ブラウザの同一Origin通信失敗と未処理の実行エラーは、その画面内だけに最大100件保持する。
発生時は「エラーを確認」ボタンを出し、「ログ → エラー」へ移動できる。
自動で表示を奪わない。画面を再読み込みするとブラウザ内履歴は消え、サーバ履歴は残る。
サーバに接続できないときもブラウザ履歴を表示する。履歴取得自身の失敗は再記録しない。
サーバのバックグラウンド処理や他サービスの全ログ収集は対象外。

登録テスト: `server/error-log/error-log.test.ts`。
