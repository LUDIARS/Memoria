# お買い物検索くん

## 目的

普段使うスーパーのチラシ、ネットスーパー、通販セールを一つの画面で巡回し、
今日のお買い得品の発見と、商品名からの送料込み価格比較を行う。

比較結果の正確さを最優先し、送料を確認できない通販候補を「最安」と断定しない。
容量、個数、会員条件、配送先で変わる最終価格は購入画面で再確認できるよう、
必ず商品ページへのリンクと内訳を表示する。

## 構成

- `server/shopping/crawler.ts`: 公開 HTTP(S) ページの取得。リダイレクトごとに
  public URL を検証し、private / loopback / link-local 宛ての SSRF を拒否する。
- `server/shopping/parser.ts`: JSON-LD と商品カード DOM から商品名、価格、送料、
  セール表示を抽出する。
- `server/shopping/service.ts`: 複数ソースを並行巡回し、送料込み総額を比較する。
- `server/shopping/crawl-coordinator.ts`: 日次・手動・検索の巡回をプロセス全体で直列化する。
- `server/shopping/config.ts`: `app_settings` に巡回先と最新ニュースを保存する。
- `server/routes/shopping.ts`: 設定、日次ニュース、商品検索の同一端末限定 HTTP API。
- `server/public/src/shopping-view.ts`: 検索、ニュース、巡回先設定の UI。

サイト固有の検索 URL は設定データに閉じ込める。既定では Amazon.co.jp の
タイムセール／商品検索、楽天市場のスーパーDEAL／商品検索、Yahoo!ショッピングの
セール・クーポン／商品検索を登録する。イオンネットスーパーとマルエツの
オンラインデリバリーも既定ソースとして登録するが、価格・配送条件が店舗や
郵便番号で変わるため初期状態では無効にする。イオンは利用店舗のトップ URL と
`<店舗URL>/search/?q={query}` を設定してから有効にする。マルエツは公開ページで
表示される見学店と利用店舗が一致することを確認してから有効にする。
スーパーはチラシ URL と、存在する場合は商品検索 URL (`{query}` を商品名に置換)
をユーザーが追加する。

## 送料の扱い

送料は次の優先順で決める。

1. ページ上の「送料無料」または送料額
2. 店頭チラシ（送料 0 円）、常時送料無料、固定送料というソース設定
3. いずれも確認できない場合は不明

送料不明の候補は一覧には残すが、最安判定から除外する。ポイント還元やクーポンは
適用条件が個人ごとに異なるため総額から自動控除せず、セールラベルとして表示する。

## 日次ニュース

ローカル時刻の設定時刻（既定 7 時）以降、当日分が無ければ一日一回巡回する。
全ソース失敗時は成功扱いで保存せず、30 分以上空けて再試行する。手動更新も可能。

## 制約

JavaScript 実行後にだけ商品を描画するサイト、ログイン必須ページ、bot 対策ページは
取得できない場合がある。失敗した店舗は結果から黙って消さず、取得失敗一覧に示す。
巡回先の利用規約と robots 方針は登録者が確認し、過度な巡回を行わない。

取得先は公開 HTTP(S) URL に限り、IPv4 埋め込み IPv6 を含む内部アドレスを拒否する。
応答本文はストリーム読み取り中に 4 MiB で打ち切り、巡回先の取得は最大 4 件ずつ行う。
同じ検索は処理を共有し、日次巡回・異なる検索・手動更新を同時に開始しないことで、
外向き通信とメモリ使用量を制限する。
